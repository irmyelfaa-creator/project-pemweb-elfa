proyek 
K-ALBUM
#Fungsi Web
Website K-ALBUM memiliki beberapa halaman utama, yaitu:
Beranda
Menampilkan informasi singkat mengenai K-ALBUM.
Menampilkan beberapa album pilihan.
Menyediakan tombol untuk melihat seluruh koleksi album.
Album
Menampilkan seluruh koleksi album K-Pop.
Menampilkan nama album, grup, harga, dan gambar album.
Pengguna dapat melihat detail album.
Pengguna dapat memasukkan album ke keranjang.
Tentang
Menjelaskan mengenai website K-ALBUM.
Menampilkan fitur-fitur yang tersedia pada website.
Kontak
Menampilkan informasi kontak K-ALBUM.
Pengguna dapat mengisi nama, email, dan pesan melalui formulir kontak.

#Fitur Utama
Koleksi Album
Website menyediakan beberapa album K-Pop dari beberapa grup, seperti
ENHYPEN, CORTIS, BTS, AESPA, NCT DREAM, dan ILLIT.
Lihat Detail Album
Pengguna dapat menekan tombol "Lihat Detail" untuk melihat gambar,
nama grup, deskripsi, dan harga album.
Keranjang Belanja
Pengguna dapat memasukkan album yang dipilih ke dalam keranjang.
Album yang sama dapat ditambahkan sehingga jumlah pembeliannya bertambah.
Mengatur Jumlah Album
Pengguna dapat menambah atau mengurangi jumlah album menggunakan tombol
"+" dan "-".
Menghapus Album
Pengguna dapat menghapus album dari keranjang. Sebelum album dihapus,
website akan menampilkan konfirmasi.
Menghitung Total Pembelian
Website secara otomatis menghitung total harga berdasarkan harga album
dan jumlah album yang dipilih.
Pemesanan Album
Pengguna dapat mengisi nama pembeli dan memilih metode pembayaran.
Setelah data lengkap dan keranjang tidak kosong, website akan menampilkan
informasi bahwa pesanan berhasil.
Formulir Kontak
Pengguna dapat mengirim pesan melalui halaman Kontak dengan mengisi nama,
email, dan pesan.
SweetAlert2
SweetAlert2 digunakan untuk membuat pemberitahuan dan konfirmasi agar
tampilan interaksi website lebih menarik dan mudah dipahami.

Cara Menjalankan Website
Pastikan semua file HTML, CSS, JavaScript, dan gambar berada dalam
satu folder project.
Buka folder project K-ALBUM.
Jalankan file `index.html` menggunakan browser seperti Google Chrome.
Pilih menu yang tersedia seperti Beranda, Album, Tentang, atau Kontak.
Pada halaman Album, pengguna dapat melihat detail album dan memasukkan
album yang dipilih ke dalam keranjang.
Setelah memilih album, pengguna dapat mengatur jumlah album dan mengisi
data pembelian untuk melakukan pemesanan.
